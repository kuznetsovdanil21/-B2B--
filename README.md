Описание проекта

Программное средство предназначено для автоматизации формирования технических заданий при проведении анализа B2B-конкурентов, исследования рынков и поиска потенциальных контрагентов.

Система позволяет аналитикам формировать структурированные технические задания на основе справочника продукции, шаблонов документов и параметров исследования.

Основные возможности
Формирование технических заданий
Управление справочником продукции
Управление шаблонами технических заданий
Поиск организаций по ИНН через DaData API
Хранение истории сформированных ТЗ
Экспорт результатов в TXT
Экспорт результатов в DOCX
Экспорт результатов в JSON
Технологии
Java 24
JavaFX
SQLite
JDBC
Apache POI
DaData REST API
Maven

Поддерживаемые форматы:

TXT
DOCX
JSON

Для получения сведений об организациях используется сервис DaData API.



В организациях, осуществляющих анализ B2B-рынка, подготовка технических заданий для поиска компаний-конкурентов выполняется преимущественно вручную. Аналитики самостоятельно подбирают ключевые слова, категории продукции, коды ОКВЭД и параметры поиска, что требует значительных временных затрат и приводит к отсутствию единого стандарта формирования аналитических запросов.

Данная проблема затрагивает аналитиков B2B-рынка, сотрудников банковских аналитических подразделений, маркетинговые отделы и руководителей аналитических проектов, использующих результаты конкурентного анализа для принятия бизнес-решений.

Ручное формирование технических заданий приводит к увеличению времени подготовки аналитических запросов, возникновению ошибок и дублированию информации. Кроме того, снижается качество поиска компаний-конкурентов, поскольку часть релевантных организаций может быть пропущена из-за некорректно подобранных параметров анализа.

Разрабатываемый программный модуль позволит автоматизировать процесс формирования технических заданий, сократить время подготовки запросов и стандартизировать процесс конкурентного анализа. Использование системы обеспечит снижение количества ошибок, повышение качества аналитических исследований, а также возможность хранения и повторного использования ранее созданных шаблонов запросов.

Разрабатываемое программное средство предназначено для автоматизации подготовки технических заданий, используемых при анализе B2B-конкурентов. Система может применяться в банковских аналитических подразделениях, маркетинговых отделах, а также во внутренних корпоративных системах анализа рынка и конкурентной среды.

Входные данные в программное средство поступают от аналитиков и руководителей проектов. Пользователь вводит сведения о продукции, ключевых словах, кодах ОКВЭД, регионах поиска и других параметрах анализа. Дополнительно могут использоваться данные из корпоративных справочников и внутренних баз компаний.

Результаты работы системы используются аналитиками, руководителями проектов и корпоративными BI-системами. Программный модуль формирует структурированные технические задания, шаблоны аналитических запросов и данные для дальнейшего конкурентного анализа.

Сравнительная характеристика программ-аналогов

В качестве программ-аналогов были выбраны системы, используующиеся для конкурентного анализа, мониторинга рынка и сбора информации о компаниях: SimilarWeb, Crayon и Crunchbase. Данные системы позволяют анализировать конкурентов, собирать рыночную информацию и формировать аналитические сведения для бизнеса.

Обозначения сегментов рынка:

XS — компании до 10 сотрудников;
S — от 10 до 25 сотрудников;
M — от 25 до 250 сотрудников;
L — от 250 до 2500 сотрудников;
C — более 2500 сотрудников.

Обозначения приоритетов:

e (essential) — обязательная характеристика;
u (useful) — полезная характеристика;
d (desirable) — желательная характеристика.

Проведенный анализ показал, что существующие программные решения ориентированы преимущественно на сбор и анализ рыночной информации, однако практически не предоставляют функциональность автоматизированного формирования технических заданий для B2B-аналитики. Разрабатываемый программный модуль отличается специализацией на стандартизации и автоматизации подготовки аналитических запросов, что позволяет сократить время работы аналитиков и повысить качество конкурентного анализа.

Существующие системы позволяют анализировать рынок и формировать отчеты, однако практически не поддерживают автоматизированное создание технических заданий. Разрабатываемый программный модуль решает данную проблему за счет стандартизации и автоматизации подготовки аналитических запросов.
Для аналитиков B2B-рынка, которым необходимо быстро формировать запросы для поиска конкурентов, программный модуль автоматизированного формирования ТЗ является системой автоматизации аналитических запросов, позволяющей сократить время подготовки и стандартизировать процесс анализа.

В отличие от ручного формирования запросов и существующих аналитических систем, продукт ориентирован на автоматическое создание технических заданий и повторное использование шаблонов.

  
Роли пользователей
Аналитик
Основной пользователь системы. Формирует технические задания, вводит параметры анализа, работает с шаблонами и экспортирует результаты.

Руководитель проекта
Просматривает сформированные ТЗ, контролирует процесс анализа и работает с отчетностью.

Сценарии использования:

Сценарий 1. Создание технического задания
Аналитик вводит параметры анализа: продукцию, ключевые слова, коды ОКВЭД и регион поиска. Система формирует структурированное техническое задание и сохраняет его в базе данных.

Сценарий 2. Использование шаблона ТЗ
Аналитик выбирает ранее сохраненный шаблон технического задания. Система автоматически подставляет параметры анализа и позволяет отредактировать данные перед сохранением.

Сценарий 3. Формирование аналитического отчета
Руководитель проекта выбирает готовое техническое задание и формирует отчет по параметрам анализа. Система создает структурированный отчет для дальнейшего использования.

Функциональные требования:
Система должна обеспечивать создание технических заданий для анализа B2B-конкурентов.
Система должна обеспечивать ввод и редактирование параметров анализа.
Система должна обеспечивать хранение шаблонов технических заданий.
Система должна обеспечивать поиск и просмотр ранее созданных ТЗ.
Система должна обеспечивать формирование аналитических отчетов.
Система должна обеспечивать экспорт результатов в файл.

Нефункциональные требования:
Время формирования технического задания не должно превышать 5 секунд.
Интерфейс системы должен быть понятен пользователю без дополнительного обучения.
Система должна обеспечивать сохранность данных пользователей.
Программное средство должно поддерживать одновременную работу нескольких пользователей.
Система должна функционировать на ОС Windows 10 и выше.
